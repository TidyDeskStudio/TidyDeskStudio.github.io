Gift Return, Exchange & Refund Deadline Tracker

Log every gift, see the last day to return it and keep refunds from slipping past their deadline.

Get it on Gumroad

You buy gifts in November, wrap them in December and by January you cannot remember which ones could still go back. A wrong size or a duplicate present turns into a refund you never claimed because the window quietly closed.

This spreadsheet keeps every gift in one list. Enter the store, purchase date and price and it works out the return-by date from each store's return window, counts the days left and flags each gift as Open, Last days or Expired. Track whether you have the receipt, mark gifts To return, Returned, Exchanged or Keeping, record refunds and keep a gift budget for each person. It is a personal record-keeping tool; store policies vary, so always check the store's own terms.

What it does

  • Gift list with recipient, store, purchase date, price, receipt and status
  • Automatic return-by date based on each store's return days
  • Days-left count and a deadline flag: Open, Last days, Expired or Closed
  • Stores tab with return windows, receipt rules and refund type
  • Gift budget per person with Nearly full and Over budget alerts
  • Refund tracking: refunds waiting and refunds received
  • Return Check tab showing what you get back after a restocking fee and postage
  • Dashboard with last-days list, missed windows, money still returnable and budget bars
