Cafe Weekly Stock Count & Par Level Order Sheet

Count stock weekly, see what is below par and get your order list by supplier, with waste tracked as you go.

Get it on Gumroad

Ordering by memory means running out of oat milk on a Saturday and throwing away croissants on a Monday. Without a par level for each item, it is hard to say what to buy and what is just sitting on the shelf.

This spreadsheet gives every item a par level, case size and cost. Type your weekly count and each row shows Out, Order now, Below par, OK or Overstocked, with the order quantity rounded up to full cases. The Suppliers tab totals the order for each supplier and tells you if it reaches the minimum, and a waste log turns thrown-away stock into a cost. The dashboard adds a waste calendar, a person spotlight, a tick-box weekly count routine, alerts and charts. Sample items are invented, so replace them with your own.

What it does

  • Stock tab with category, supplier, unit, par level, case size and unit cost
  • Automatic status per item: Out, Order now, Below par, OK or Overstocked
  • Order quantity rounded up to full cases, with order cost and stock value
  • Suppliers tab with order day, lead time, minimum order and an order total per supplier
  • Under minimum and Ready to order flags so each supplier order is easy to place
  • Waste log with reasons and an automatic cost for every entry
  • Dashboard with a waste calendar, person spotlight dropdown, tick-box count routine and attention lists
  • Charts for waste by month, stock value by category and order value by supplier, with sample data and a Quick Start Guide

What you get

  • Cafe Weekly Stock Count & Par Level Order Sheet (.xlsx)
  • Quick Start Guide (PDF)

Works with: Works in Microsoft Excel 2016 or newer (Windows & Mac) and Google Sheets. No macros.
